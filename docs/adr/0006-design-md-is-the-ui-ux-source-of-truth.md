# ADR-0006: DESIGN.md is the UI/UX source of truth

- **Status:** Accepted
- **Date:** 2026-10-09
- **Decided by:** Sumiran

## Context
Two products and two front ends must feel like one family, at a high polish bar.

## Decision
DESIGN.md defines feel, voice, colour tokens, motion physics, keymap, consent patterns and the definition of done. Changes need both owners.

## Consequences
Code that disagrees with DESIGN.md is a bug, or DESIGN.md is changed first.
